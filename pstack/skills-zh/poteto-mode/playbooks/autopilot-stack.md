### 堆叠式自动驾驶（Autopilot-stack）

运行全自动驾驶手册，但不合并。

1. **代替第 5 步，停在已验证。** 当每个 PR 在其当前 head 上已验证且全绿时停下，然后把 PR 交给操作者。交接之后，没有操作者的放行谁也不许推送。每个循环 tick 的提示都会点名本文件，因此每个 tick 都能看到不合并规则。
2. **只有在某个 PR 建立在另一个 PR 之上时才堆叠。** 这是第 3 步唯一的例外。按 `playbooks/opening-a-pr.md`，让该 PR 基于另一个 PR 的分支而非主干。代替第 2 步的 rebase 到主干，每个 PR rebase 到其父 PR 的分支，堆叠根则 rebase 到主干。下层 PR 出现新 head 时，其上方 PR 重新堆叠；如果重新堆叠后某个 PR 的 `git patch-id` 未变，它就保留原有裁决。

**回复：** 逐个列出每个 PR 及其裁决，代替"合并了什么"。
