### 编写或修改 Skill

**你负责 Skill 的声音。**

1. 使用 **create-skill** skill（Cursor 内置的 SKILL.md 编写工具）。
2. 校验 Skill：frontmatter 含 `name` 与 `description`，被引用的文件存在，跨 Skill 链接可解析。
3. 结构性改动写测试用例。主观性改动跳过。
4. 运行 **Opening a PR** 手册。

拿不准就删。只保留能改变决策的文字。直接说做什么，略去原因。只有规则缺少原因会令人困惑时才解释。语气与范围相匹配。按 **encode-lessons-in-structure** 原则 skill，指向结构性来源（类型、README、配置）。按路径委派给其他 skill。不要复述。反复遇到却未被收录的工作流 → 提议新建 skill。

**回复：** Skill 概要、关键设计决策、校验说明。
