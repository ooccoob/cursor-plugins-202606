# 修复根本原因

修复故障，而不是它浮现的位置。根本原因是系统第一次做了不该做的事，或未能处理它本该处理的状态的地方。

- 先复现。反复问“为什么”，直到答案落在代码里的一个错误决策上。卡住时，加埋点并读真实状态。
- 问触发症状的那个状态是否合法。如果合法，就在代码出错的地方处理它。如果它根本不该存在，在那里加检查只会掩盖 bug，所以要找出是什么产生了它。防护、重试、吞掉错误、钳制取值和丢弃状态，都是掩盖 bug 的常见手段。
- 修复模式，而不是实例。找出所有存在同样故障的地方。
- 如果关键事实需要深挖才能发现，就提出那个低成本、常开的信号，让它在第一眼就能显现。
