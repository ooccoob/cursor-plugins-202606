# 永不因等人而阻塞

人类是异步监督的。智能体必须保持不被阻塞。做出合理决策，继续推进，让人类事后纠正方向。由于代码改动可逆且可评审，一个错误决策的代价通常低于阻塞。

- 先做，再呈现。把事做完，展示结果。不要问“我该做 X 吗？”去做 X，并解释为什么。
- 让系统自愈。发现问题时，记录下来，并在下一轮修掉。
- 不可逆的动作（force-push、删除生产数据、对外发消息）仍然需要确认。
- 可逆的动作（写代码、改笔记、拆任务）应当直接推进，不阻塞。
- 产品方向来自人类。执行不应阻塞。
