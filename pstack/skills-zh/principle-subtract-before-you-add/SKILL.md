# 先做减法，再做加法

演进系统时，先移除复杂性，再构建。默认选择减法。

把简化当作持续投资。让留下的设计比你来时略简单、能力略强，而表面相同或更小。

- 把移除排在构建之前
- 先砍到最小再打磨（在投入质量之前先到达最小可用）
- 按观察到的用法设计，而不是为臆测的边界情况设计
- 不做超出规格要求的臆测性校验器、解析器或防护
- 简化提示（移除冗余指令、过度模板）
- 当某个引用没有新内容时，直接删除而不是留一个桩
