# 把工作排成可验证的单元

把工作排成小单元，每个都结束于一个可检查的状态；当前单元未变绿之前不前进。

在清扫、迁移或一串相似编辑中，每个单元是一对括号：已知良好状态、一处改动、运行检查、继续。即使工具替你做了编辑，也要运行单元级检查。

按能证明工作的顺序交付：先失败的测试，再修复。先减法，再重塑。先基线，再处理。每个 commit 各自落地。
