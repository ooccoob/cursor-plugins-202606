# 如何（How）

探索代码库来回答“X 是怎么工作的？”这类问题。

如果范围有歧义，先说出你的理解再探索。用户可以纠正方向。

## 1. 解释

派生一个 Task 子代理，参数为 `subagent_type: generalPurpose` 和 `readonly: true`，让它一趟完成探索与解释。把用户的问题和下面这段简述交给它：

> 你在为一位资深工程师撰写架构说明。探索代码库，写一份解释，让一位不熟悉这块领域的资深工程师读完能带走扎实的心智模型。他应当理解架构到足以自信地开始在其中工作。你对代码库有只读权限。

## 2. 呈现

呈现子代理的输出。为清晰起见做轻微编辑，或补上对话中的上下文，都可以。不要大幅重写。
