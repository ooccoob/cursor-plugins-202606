# 类型系统纪律

让编译器拒绝不可能的状态、语义不匹配的基本类型，以及未被处理的变体。

- **为语义化基本类型打上标记。** 如果两个参数共享同一种基本类型但含义不同，就各给它们自己的类型。在创建时校验一次。
- **外部数据在被解析之前是无类型的。** JSON、RPC 载荷、CLI 参数、配置、环境变量和数据库行，都在边界经过一个解析函数，返回带类型的模型。
- **从权威 schema 派生类型。** 当某个 schema 文件拥有某种形状时，从它派生类型，而不是手写一份平行的。

TypeScript 语法见 **typescript-best-practices** 技能。
